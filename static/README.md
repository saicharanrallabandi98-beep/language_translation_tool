# 🌍 Language Translation Tool

A simple and user-friendly Language Translation Tool built using Python and Flask.  
This application allows users to translate text between multiple languages quickly and efficiently.

---

## 🚀 Features

- Translate text into multiple languages
- Easy-to-use web interface
- Fast and accurate translations
- Built with Flask and Python
- Clean and responsive design

---

## 🛠️ Technologies Used

- Python
- Flask
- HTML
- CSS
- JavaScript
- Translation API
